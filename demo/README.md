# Demo

## 演示范围

`scenarios.json` 包含三组完全合成的研究场景。`DEMO-WALLET-*` 是展示标识，不是链上地址。这里没有交易哈希、真实收益、真实执行次数或已核验的当前状态。

## 90 秒演示脚本

1. **0–15 秒：研究入口。** 选择 Energy Rental，说明已知机制如何帮助筛选值得进一步研究的执行者。
2. **15–35 秒：钱包路径。** 点击 Wallet，说明真实场景需要从成功交易定位调用者，区分钱包、代理与奖励接收者。
3. **35–55 秒：候选假设。** 点击 Candidate，展示跨合约行为如何形成新的研究问题。
4. **55–75 秒：验证。** 点击 Validation，说明候选仍为 `UNCERTAIN`，缺失交易、资金流和当前状态证据。
5. **75–90 秒：扩展。** 切换 USDD 与 JustLend，说明 Seed 的信号质量不同；展示现有 Pitch Deck。

当前演示支持产品流程评审。真实 MVP 仍需以真实 Seed → 真实执行者 → 新候选 → 证据验证形成闭环。

## 替换为真实数据

另建研究数据文件，逐项提供 chain、network、contract、transaction hash、block、timestamp、查询时间、数据来源和覆盖区间。缺失项明确为 unknown。只有完成证据核验后才能更新展示状态与标签；不能仅将 `mode` 改成 `live`。
